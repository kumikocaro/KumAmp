Despues de instalar

  • REAPER / Ableton / Cubase / Studio One: vuelve a escanear los plugins si KumAmp no aparece.
  • Logic Pro: abre Logic Pro > Ajustes > Plug-in Manager y pulsa Reset & Rescan si no aparece.
  • Aplicacion: la primera vez macOS pedira permiso para usar el microfono (la entrada de audio): aceptalo.

Modelos NAM e IRs

KumAmp no incluye modelos: descarga capturas .nam (por ejemplo de Tone3000) e IRs .wav y cargalos desde los bloques Amp y Cab.

Desinstalar

Borra estos elementos (Finder > Ir > Ir a la carpeta):

  • /Library/Audio/Plug-Ins/VST3/KumAmp.vst3
  • /Library/Audio/Plug-Ins/Components/KumAmp.component
  • /Applications/KumAmp.app
